# Wallpaper

Add .png files here. Pick one in Settings > Shelf > Wallpaper.

Slot.png and Slot Blur.png are slot's own. Delete them if you don't
want them; they won't come back.

Make it your screen size:

  Device         Size
  RG SP          720 x 480
  RG 34XX        720 x 480
  RG 34XXSP      720 x 480
  RG 35XXSP      640 x 480
  RG 35XX Plus   640 x 480
  RG 35XX-H      640 x 480
  RG 28XX        640 x 480

Other sizes are scaled to fill the screen and cropped from the centre.

Pick Per Shelf to change wallpaper with the shelf. Name the files:

  GB.png, GBC.png, GBA.png, GBAV.png, Favorites.png, Recents.png

Game Boy Advance Video uses GBA.png if there is no GBAV.png. A shelf
without a file shows Default.png, or nothing if there is no Default.png.
