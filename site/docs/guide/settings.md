# Settings Explained

Tap <kbd>MENU</kbd> on the shelf to open settings. 

All settings save as soon as you change an option.

## General

| Setting | Choices | Default | Does |
| --- | --- | --- | --- |
| Theme | Dark, Light | Dark | The look of the shelf and menus |
| Wallpaper | None, Random, Shelf, Default, Default Blur, your own | Default | What's behind the shelf |
| Wallpaper Tint | Off, 25%, 45%, 65% | Off | Darkens your own wallpaper so carts stand out. Only shows for your own, Random or Shelf |
| Shelf Mode | All, Collections | All | Collections hides the system shelves and puts your [collections](collections.md) in the row |
| Recents | Show, Hide | Hide | A shelf of your last 10 games |
| Game Titles | Show, Hide | Hide | Shows the name of the cart you're on |
| Lid Power Off | 1, 3, 5, 10, 15, 30 min | 3 min | How long slot sleeps before powering off |
| Kid Mode | Off, One Shelf, Shelves | Off | Locks slot so a kid can only pick a game and play it, see [Kid Mode](#kid-mode) |
| Kid Shelf | All Games, any shelf | All Games | The one shelf a kid sees.<br>Only shows for One Shelf |
| Date & Time | | | Sets the clock, your city and 12 or 24-hour time |

Random picks a different wallpaper each boot. 

The `Shelf` option gives each shelf its own wallpaper, see [Wallpapers](customizing.md#wallpapers).

### Kid Mode

Kid Mode lets them have fun retro gaming without the fear of messing up any settings.

When kid mode is enabled a teddy bear will appear in the status bar.

- **One Shelf** shows a single shelf. Pick it with Kid Shelf: All Games puts every game on one shelf from A to Z, or
  choose one of your shelves or collections.
- **Shelves** keeps the shelves you have now, and L1, R1, L2 and R2 still move between them.

On the shelf, the menu, favoriting, collections, the core picker and Cart Studio are all disabled. 

In a game, a tap of menu saves and goes back to the shelf. L2 and R2 turn the brightness down and up. Rewind, fast forward, save states, screenshots and every shortcut are disabled. Volume, power and the lid work as usual.

To disable kid mode, hold <kbd>START + SELECT + L2 + R2</kbd> while turning the device on. Kid Mode
is off until the next restart, so you can change settings or turn it off for good. Restart without the buttons and it
locks again.

## Screen

### General

| Setting | Choices | Default |
| --- | --- | --- |
| Brightness | 0 to 9 | 5 |
| Blue Light | Off, 1 to 9 | Off |
| Saturation | Off, 1 to 9 | Off |
| Contrast | Off, 1 to 9 | Off |

### Game Boy Advance, Game Boy Color and Game Boy

Each system has its own page.

| Setting | Choices | Default |
| --- | --- | --- |
| Shader | GBA: Off, LCD, Grid, Dot, Shimmerless (4:3 devices only). GB and GBC: Off, LCD, Grid, Simpletex, Shimmerless | Grid on GBA, Simpletex on GB and GBC |
| Color Correction | On, Off | Off |
| Palette | Game Boy only. Auto, then 48 palettes | Auto |
| Scale | GBA: Fit, Integer, Full Screen. GB and GBC: SP Screen, Integer, Fit | Fit on GBA, SP Screen on GB and GBC |
| Stretch | GB and GBC only. Classic, Full Screen | Classic |
| Frame Blending | Off, Mix, Ghosting | Off |
| Bezel | None, Default, AGS-102, your own | AGS-102 on 640×480 devices, None elsewhere |

See [The Screen](screen.md) for what Scale, Stretch, Frame Blending, Saturation and Contrast do.

## Gameplay

| Setting | Choices | Default | Does |
| --- | --- | --- | --- |
| Fast Forward | Off, 1.5x, 2x, 3x, 4x, 6x | 6x | The top speed when fast-forwarding |
| Fast Forward Sound | On, Off | Off | Sound while fast-forwarding |
| Rewind | On, Off | On | Hold <kbd>L2</kbd> to go back |
| Turbo Buttons | On, Off | On | Turbo A and Turbo B |
| Rumble | On, Off | On | For games with a rumble pak |
| Left Stick as D-Pad | On, Off | On | Only on devices with a left stick |
| Auto Load State | Always, Power On, Never | Always | Inserting a cart picks up where you left off.<br>Power On resumes only the game you powered off in |
| Eject Save State | On, Off | On | Ejecting saves where you were |

## About

Your device's sticker, with the version of slot and more. Press <kbd>X</kbd> to restart.

## The in-game menu

Tap <kbd>MENU</kbd> while playing for Resume, States, Screenshots, Settings and Exit Game.

Settings while in-game has the Screen and Gameplay pages for the system you're playing, and the In-Game controls. Shortcuts and shelf keys can only be customized from settings accessed from the shelf.
