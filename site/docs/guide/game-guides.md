# Game Guides

## Adding a guide

Put a `.txt` file in the `Guides/` folder for the system, named the same as the game:

| Game                    | Guide                    |
|-------------------------|--------------------------|
| `Games/GBA/Pokemon Emerald.gba` | `Guides/GBA/Pokemon Emerald.txt` |

## Opening a guide

Open the in-game menu and pick Guide. The row only shows up if the game has a guide.

You can also set a Guide shortcut under Controls. This is unbound by default.

## Reading

| Button                          | Does         |
|---------------------------------|--------------|
| Up and Down                     | Scroll       |
| Left and Right                  | Pan          |
| <kbd>L1</kbd> and <kbd>R1</kbd> | Page         |
| <kbd>A</kbd> and <kbd>B</kbd>   | Zoom in, out |
| <kbd>X</kbd>                    | Wrap         |
| <kbd>MENU</kbd>                 | Help         |
| <kbd>Y</kbd>                    | Close        |

A guide opens at the largest size that shows 80 columns. Each guide remembers your place, size and wrap setting.
