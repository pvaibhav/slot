# Controls

Four submenus for adjusting controls can be found in Settings → Controls.

- **Shelf**: the keys for getting around the shelf. Previous Shelf, Next Shelf, Favorite and Remove Recent.
- **Collections**: the keys for flipping through [collections](collections.md), Previous and Next.
- **Shortcuts**: everything you do with a chord in game. Save and load states, brightness, blue light, shaders, palettes, color correction, screenshots, fast-forward, rewind and the [solar sensor](playing.md#solar-sensor).
- **In-Game**: which console button each button on your device presses. This is where you'd swap A and B, or move Turbo A and Turbo B off X and Y.

All four apply globally. The In-Game page is also in the in-game menu, for on-the-fly remapping.

## Changing a button

Pick a row and press <kbd>A</kbd>. 

It will say `Recording` while it waits for you to press a button or buttons.

| Button | Does |
| --- | --- |
| <kbd>A</kbd> | Set the row |
| <kbd>X</kbd> | Clear it, so nothing does it |
| <kbd>Y</kbd> | Reset the whole page to the defaults |

Shortcuts and shelf keys take a single button or two held together, like <kbd>L1</kbd> + <kbd>R1</kbd>. In-Game takes a single button or <kbd>MENU</kbd> plus a button.

<kbd>SELECT</kbd>, <kbd>START</kbd> and <kbd>MENU</kbd> only work as the first button of a chord.

If two rows end up on the same button, both get a warning triangle and slot shows a toast saying what it clashes with.

## How chords work in game

<kbd>SELECT</kbd> is still a button your game needs, so slot waits a moment before deciding. Press <kbd>SELECT</kbd> and then the second button within about half a second and you get the shortcut. Otherwise the game gets <kbd>SELECT</kbd>.

For other chords, the first button goes to the game straight away and the second fires the shortcut.

## Volume

<kbd>VOL+</kbd> and <kbd>VOL&minus;</kbd> change the volume. 

Press both together, or <kbd>SELECT</kbd> + <kbd>VOL+</kbd> or <kbd>VOL&minus;</kbd> to mute.

The speaker and headphones each keep their own volume level and mute status.

## The left stick

On devices with a left stick, it works as the D-pad. You can turn off Left Stick as D-Pad in Settings → Gameplay.
