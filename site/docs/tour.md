### Browse the Carousel { #browse data-clip="carousel.mp4" }

<kbd>Left</kbd> and <kbd>Right</kbd> to flip through games.<br><kbd>L1</kbd> and <kbd>R1</kbd> to switch platforms.

### Favorites { #favorites data-clip="favorites.mp4" }

Press <kbd>Y</kbd> to heart the cart you're on.<br>Press <kbd>Y</kbd> again to remove.

### Cart Studio { #cart-studio data-clip="studio.mp4" }

Press <kbd>SELECT</kbd> to open the cart studio.<br>Print a new label when you are on Wi-Fi.<br>You can also change the shell color and finish.<br>Label Printer needs Wi-Fi.

### Pick an Emulator { #core-picker data-clip="core-picker.mp4" }

Press <kbd>START</kbd> to open a cart.<br><kbd>Left</kbd> and <kbd>Right</kbd> swap the core "chip".<br><kbd>A</kbd> saves your choice.

### Insert and Play { #insert data-clip="insert.mp4" }

Tapping <kbd>A</kbd> loads the last save state.<br>Holding <kbd>A</kbd> starts the game fresh.

### Ejecting a Game { #eject data-clip="eject.mp4" }

Hold <kbd>MENU</kbd> to eject the cart.<br>On exit, slot creates a save state.

### Save States { #save-states data-clip="states.mp4" }

<kbd>SELECT</kbd> + <kbd>R1</kbd> creates a save state.<br><kbd>SELECT</kbd> + <kbd>L1</kbd> loads the most recent.

### Save State Switcher { #switcher data-clip="switcher.mp4" }

Double tap <kbd>MENU</kbd> to view your save states.<br><kbd>A</kbd> loads the one currently selected.<br><kbd>B</kbd> goes back to the game.

### Fast-Forward and Rewind { #fast-forward data-clip="rewind.mp4" }

Hold <kbd>R2</kbd> to fast-forward.<br>Double tap <kbd>R2</kbd> to lock FF on.<br>Hold <kbd>L2</kbd> to rewind.

### Commit Aspect Ratio Crimes { #expand data-clip="gbc-stretch.mp4" }

<kbd>L1</kbd> stretches GB and GBC games.<br><kbd>R1</kbd> puts them back to their original size.

### Screen Shaders { #shaders data-clip="shaders.mp4" }

<kbd>SELECT</kbd> + <kbd>B</kbd> / <kbd>A</kbd> changes the active shader.<br><kbd>SELECT</kbd> + <kbd>Y</kbd> toggles color correction.

### Game Boy Palettes { #palettes data-clip="palettes.mp4" }

<kbd>SELECT</kbd> + <kbd>L2</kbd> / <kbd>R2</kbd> steps through them.

### Link Up { #link data-clip="link.mp4" data-pair="link-join.mp4" }

<kbd>SELECT</kbd> + <kbd>MENU</kbd> opens the link screen.<br>Host on one SP, Join on the other.<br>The link is hosted over its own Wi-Fi network.

### Settings { #settings data-clip="settings.mp4" }

Tap <kbd>MENU</kbd> to open settings.

### Brightness and Blue Light { #brightness data-clip="brightness.mp4" }

<kbd>SELECT</kbd> + <kbd>Up</kbd> / <kbd>Down</kbd> adjusts brightness.<br><kbd>SELECT</kbd> + <kbd>Left</kbd> / <kbd>Right</kbd> adjusts blue light.<br>You can change both on the carousel or in-game.

### Lid Detection { #lid-detection data-still="carousel.webp" data-lid="shut" }

Closing the lid writes a save state and turns off the display. Open it and you're back in the game.

Leave it shut for three minutes and slot powers off. It will resume with that save state on the next boot.
