Installing

  1. Flash BaseOS to an SD Card

    Download the latest release of BaseOS and write the .img to an SD card with something like Raspberry Pi Imager.

    Insert this card into the SD card slot labeled SD1.

  2. Expand the storage

    After inserting the SD card, power on your device. You should see a BaseOS boot logo and a message saying that storage is being expanded.

    Once the storage is expanded, a message will say that no frontend was found. Power off your device.

  3. Download the latest release

    Go fetch the latest slot release from GitHub.

  4. Copy it onto your SD Card

    Eject the SD card from SD1 and connect it back to your computer. Unzip the release zip you downloaded and copy the contents to the root of the SD card.

  5. Add your games

    Drop your legally obtained ROM files into their corresponding platform's folder in Games/. You may optionally place labels into the matching platform folder found in Labels/.

  6. Re-insert the card into SD1 and boot!

    I hope you enjoy using slot!

Updating from a version before 1.4.0?

Older versions kept settings in System/, so deleting it wipes them.

This time, copy the new System/ over the old one instead of deleting it. slot will move your settings into a new Config/ folder, so future updates can delete System/ as normal.

Your games, saves and save states aren't affected.

Sorry for the hassle! slot started as a throwaway project for my own SP, and I never expected it to need an update procedure.

  1. Download the latest release

    Go fetch the latest slot release from GitHub and unzip it.

  2. Replace the System/ folder

    Connect the card that holds slot to your computer. That is the card in SD1 if you use a single card, or the card in SD2 if you use two.

    Delete the System/ folder on the card and copy the new System/ folder from the release in its place. Your games, saves, save states, labels and wallpapers all live outside System/ and are left alone.

  3. Put the card back and boot!

User guide

  1. Browse the Carousel

    Left and Right to flip through games on the shelf.
    L1 and R1 to switch platforms.

  2. Pick an Emulator

    Press START to open a cart.
    Left and Right swaps the core "chip".
    A saves your choice.

  3. Insert and Play

    Tapping A loads the last save state.
    Holding A starts the game fresh.

  4. Ejecting a Game

    Hold MENU to eject the cart.
    On exit, slot creates a save state.

  5. Save States

    SELECT + R1 creates a save state.
    SELECT + L1 loads the most recent.

  6. Save State Switcher

    Double tap MENU to view your save states.
    A loads the one currently selected.
    B goes back to the game.

  7. Fast-Forward and Rewind

    Hold R2 to fast-forward.
    Double tap R2 to lock FF on.
    Hold L2 to rewind.

  8. Commit Aspect Ratio Crimes

    Just like the OG, L1 stretches GB and GBC games.
    R1 puts them back to their original size.

  9. Link Up

    SELECT + MENU opens the link screen.
    Host on one SP, Join on the other.
    The link is hosted over an Ad Hoc network.

  10. Settings

    MENU on the carousel opens the settings.

  11. Brightness and Blue Light

    SELECT + Up / Down adjusts brightness.
    SELECT + Left / Right adjusts color temperature.
    You can change both on the carousel or in-game.

  12. Lid Detection

    Closing the lid writes a save state and turns off the display. Open it again and you're back in the game.


    Leave it shut for three minutes and slot powers off. It will resume with that save state on the next boot.

Anticipated Questions Answered

Will slot run anything other than GBA?
Yes. You can bring your GB and GBC carts to the party.
This is almost perfect but needs more systems. Will you add them?
No. I want to recreate the feeling I had playing my GBA SP as a child.
Does slot allow you to pair Bluetooth headphones?
No. Use the headphone jack.
How do I add cart labels?
When online, slot automatically fetches missing cartridge labels and shows them as they arrive. You can also drop your own .png into the Labels/ folder for that platform, named after the ROM. For example, Labels/GBA/Metroid Fusion.png matches Games/GBA/Metroid Fusion.gba. Existing labels are kept.
Do I have to craft them by hand?
No. slot prepares downloaded labels automatically. If artwork is unavailable, it keeps a text label. Failed downloads have limited retries and can be tried again on the next launch. You can also use the slot Cart Studio.
Where do games go?
Each platform has its own folder under Games/.
Is there a BIOS boot animation on game start?
Yes! Drop the following files you legally obtained into BIOS/.
  • gba_bios.bin
  • gbc_bios.bin
  • gb_bios.bin
Where do the games come from?
Your own legally obtained backups.
Can I trade Pokémon with a friend?

Yes, with a second RG SP running slot.

First, navigate to the game and press START to open the core selection menu. Pick gpSP.

While in game, press SELECT + MENU and choose LINK.

One player needs to pick HOST while the other chooses JOIN.

Which games can link?

Pokémon Emerald, LeafGreen, and FireRed.

Additionally, both Advance Wars have worked for me.

A hacky implementation of link play using mGBA can be used to play Mario Kart Advance.

Do you accept contributions?

I am not opposed to accepting pull requests. I just ask that you come discuss planned work in an issue on GitHub ahead of time.

slot is intentionally light on features. I am not looking to add the kitchen sink. If this form of collaboration doesn't appeal to you, several individuals have forked slot and gone off to make it their own.
